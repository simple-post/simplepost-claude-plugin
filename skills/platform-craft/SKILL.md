description: Adapts copy for supported social platforms. Use for write a post, caption, tweet, thread, social copy, or adapt for.

Apply the platform guidance below to the user's idea and voice. Preserve facts and intent; adapt structure and emphasis instead of performing a mechanical cross-post.

- **X:** Make the first line carry the claim, tension, or useful surprise. Keep a single post centered on one thought; use a thread only when each reply advances the argument. Include a link when it is genuinely the next step, not as a substitute for the post. Use hashtags sparingly and mention people only when directly relevant. Avoid the generic announcement opener that delays the point.
- **Threads:** Open conversationally, with an observation or opinion that invites a response. Use short, natural paragraphs; split into a thread when the idea benefits from turns rather than compression. Treat links as supporting context, not the entire post. Prefer natural language over hashtag stacks, and use mentions for real participants. Avoid recycling terse X copy without restoring context and warmth.
- **Instagram:** Put the hook before the caption is visually truncated, then let the caption add meaning to the visual rather than narrate it. Use line breaks and a clear close; make any link direction realistic for the account's available surfaces. Use focused hashtags and collaborator mentions only when they improve discovery or attribution. Avoid writing a caption that assumes a strong visual when none has been selected.
- **Facebook:** Lead with why the post matters to this audience, then use readable paragraphs and enough context for someone who has not followed the whole story. Let a useful link and its preview support the post. Keep hashtags rare and tag only genuine people or pages. Avoid ad-like copy that suppresses the human reason to care.
- **Telegram:** Lead with the update or benefit because subscribers are reading a feed. Use compact sections, bullets, and direct links when helpful; use hashtags mainly for channel navigation and mentions for community context. Avoid an unbroken broadcast wall with no scan path.
- **YouTube:** Make the opening promise match the actual video. Structure the description so the summary, useful resources, and next action are easy to find; keep links clearly labelled. Use a small number of relevant hashtags and valid creator mentions. Avoid pasting a generic social caption that ignores what the viewer will watch.
- **Bluesky:** Start directly and write for a conversational, community-aware feed. Use a thread when context or evidence needs distinct beats. Place links naturally, use hashtags only where they aid discovery, and mention exact accounts when participation matters. Avoid hashtag-heavy copy or unexplained cross-post references from another network.

This skill shapes copy only. Any publishing or scheduling must go through the `post-review` skill and its explicit approval gate.
